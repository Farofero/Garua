## 📖 Sobre o projeto

**Garuá** é um jogo educativo criado para **ensinar sobre reciclagem** e **conscientizar os moradores do Guará (DF)** sobre a importância de cuidar das pracinhas e dos espaços de lazer da cidade.

Durante a história, o jogador aprende a **reciclar corretamente** e a **manter o ambiente de lazer limpo**. Para engajar o público infantil, o projeto conta ainda com um **mascote** que incentiva e motiva os jogadores.

> 💡 O jogo foi pensado para ser **simples, divertido e de fácil aprendizagem**, acessível a qualquer pessoa com acesso à internet.

## 🎯 Objetivos

- ♻️ Ensinar o descarte correto de resíduos recicláveis
- 🌳 Promover o cuidado com as praças e áreas de lazer do Guará
- 🧒 Engajar o público infantil por meio de um mascote e de uma narrativa lúdica
- 📣 Incentivar a **coleta seletiva** no cotidiano da comunidade

## 🕹️ As 3 fases

| Fase | Cenário | Objetivo |
|:---:|---|---|
| **1️⃣** | 🗑️ Ambiente sujo e cheio de lixo | O jogador é provocado pelo cenário e deve **pular sobre o lixo** para avançar |
| **2️⃣** | ♻️ Coleta de recicláveis | O jogador **recolhe o lixo reciclável** e o **deposita nas lixeiras corretas** |
| **3️⃣** | 🌿 Lugar limpo e bem cuidado | O jogo mostra o resultado do cuidado coletivo, promovendo a **conscientização** sobre a coleta seletiva |

## 🚀 Como executar

O jogo roda direto no navegador, sem necessidade de instalação.

```bash
# 1. Clone o repositório
git clone https://github.com/arthurcavalcante/garua.git

# 2. Entre na pasta do projeto
cd garua

# 3. Abra o arquivo index.html no navegador
# (ou use a extensão Live Server do VS Code)
```

## 🔬 Metodologia

O desenvolvimento seguiu três frentes:

1. 🔎 **Pesquisa** em sites e artigos da internet
2. 🧭 **Pesquisa de campo** nas pracinhas e espaços de lazer do Guará
3. 🏁 **Construção do projeto** com foco em resultados satisfatórios e em uma experiência acessível

## ✅ Resultados

- 🎮 Jogo desenvolvido em **JavaScript**, com **três fases** e uma história sobre a importância de zelar pelos espaços de lazer
- 🐶 Criação de um **mascote** para motivar o público infantil
- 🌐 Implementação simples e de fácil aprendizagem, acessível a qualquer pessoa com internet
- 🏫 Divulgação por meio de apresentações para a banca avaliadora e para a comunidade escolar, com planos de divulgação futura nas redes sociais (Instagram)
